Personal assistant / Application information

A personal assistant.
With clear data boundaries.

Wei Personal Assistant is a privately operated tool for its owner: text tasks, personal notes, Gmail notifications and Google Calendar queries through a private Telegram conversation.

This is an information website. The assistant is for the owner's personal use and does not offer public registration or Google sign-in here.
01 / Connected information

Mail and schedule, read only

Reads the owner's Gmail message metadata and snippets for new-mail monitoring, and events from the owner's primary Google calendar. It does not send email or modify calendar events.

02 / Text assistance

Rules first, models when needed

Rules handle notes and status queries. Other text tasks use Kimi or OpenAI APIs according to task routing and configured usage limits. Google monitoring data is not automatically sent to these models.

03 / Owner access

A private mobile channel

Queries and notifications use a Telegram bot restricted to the owner's bound private chat. Telegram bot conversations are not end-to-end encrypted.

04 / Owner control

Access can be revoked

The owner can disconnect Google access and request deletion of retained assistant data. Details of data retention and deletion are explained in the privacy policy.
