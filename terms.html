Use / Support / Control

Personal use.
Owner in control.

Wei Personal Assistant is a privately operated tool for one owner. This website describes the application; it is not a public assistant service.

Current scope

The cloud service supports personal text assistance, notes, read-only Gmail and primary-calendar queries, and owner-only Telegram notifications. Model-based text assistance may incur charges with the owner's API providers. Website hosting does not make model calls free.

Review and limitations

Generated text can be inaccurate and should be reviewed before use. Calendar access remains read-only. Optional Gmail sending requires separate Google consent and the owner's approval of each specific email. Cloud operation depends on connectivity and provider availability;

Disconnect or request deletion

  1. Revoke the Google connection in Google Account connections to stop future Google access.
  2. Contact the operator to remove retained server records or credentials. Revocation alone does not delete existing data.
  3. Delete previously delivered copies in Telegram separately, if desired.
